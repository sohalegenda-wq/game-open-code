# Проверка сборки

Дата: 4 ноября 2026.

## Выполнено

- Архив распакован в отдельный каталог без node_modules, build и local.properties; `npm ci` и `npm run build:apk` успешно выполнены с ANDROID_HOME.
- Готовый APK проверен apksigner: подписи v1/v2 действительны; package ID com.observer.signallost, minSdk 23, targetSdk 34. Файлы HTML/CSS/JS внутри APK побайтно совпадают с www/.
- Android debug APK собран через `npm run build:apk` (Capacitor sync + Gradle assembleDebug), с JDK 17, SDK Platform 34, Build Tools 34.0.0 и Gradle 8.7.
- В Chromium проверены генерация всех 15 зон, неизменность лабиринта при повторной генерации, закрытые границы, BFS-путь к выходу и достижимость стартов монстров.
- Проверены D-Pad, стены, задержка 120 мс между шагами и события свайпов.
- Проверены истощение энергии, запрет включения при перегреве, восстановление при 30% и отмена отложенного lightGlitch после отпускания.
- Проверены отступление монстра, смерть от второго монстра и повтор той же зоны.
- Телепорт проверен на связность по полу и отсутствие приземления на игроке.
- Проверены приостановка и возобновление через события native lifecycle с двумя монстрами: позиции, аккумуляторы и игровое время в паузе не менялись.
- Проверены все 15 переходов VICTORY, запись следующей зоны, продолжение после перезагрузки, сброс прогресса после финала.
- Отдельный автоматический игрок прошёл все 15 зон с работающим rAF, включённым движением монстров, обходом занятых ими клеток и использованием света при приближении. Это проверка достижимости победы, а не оценка сложности для человека.
- Проверены кнопки не менее 64×64 и разделение 55/45 на экранах 320×640, 360×740 и 390×844.
- Проверены fallback при отказе localStorage, prefers-reduced-motion, отсутствие внешних запросов игровой страницы и ошибок JavaScript.
- Все 45 сюжетных реплик получены дословно из мастер-спеки; они хранятся в LEVELS.

## Ограничения проверки

Приложение не запускалось на физическом Android-телефоне или Android-эмуляторе. Браузерные проверки событий жизненного цикла не заменяют проверку сворачивания на устройстве. Фактическую громкость, поведение конкретной версии WebView и ощущения от управления следует проверить на телефоне. Длительная балансировка сложности и полное покрытие всех случайных ходов монстров не проводились.
